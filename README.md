# DevForge - Client-Side Developer Utilities Platform

A lightweight, privacy-focused, and fast developer utility web platform built with pure client-side JavaScript.

## 🚀 Features
- **100% Client-Side Processing:** Zero data sent to servers.
- **Comprehensive Toolset:** Code Formatters, Encoders, Crypto Utilities, JSON Tools, Markdown Converters, and Text Tools.
- **Monetization Ready:** Pre-built ad spaces for AdSense or sponsors.
- **Compliance:** Built-in GDPR Cookie Consent banner.

## 🛠️ Tech Stack
- HTML5, CSS3
- JavaScript (ES6 Modules)
- Node.js (Optional local development server)

## 💻 Getting Started
1. Clone this repository.
2. Run `node server.js` to start the local development server.
3. Open `http://localhost:3000` in your browser.
